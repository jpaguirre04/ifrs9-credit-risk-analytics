# Proyecto IFRS 9: Análisis de Préstamos y Rechazos (Lending Club)

Implementación en Python de modelos y metodologías para el cálculo de provisiones bajo la norma **IFRS 9** utilizando datos históricos de Lending Club (préstamos y solicitudes rechazadas).

## Contenido del Proyecto
- Preprocesamiento de datos de aceptados y rechazados de Lending Club.
- Estimación de componentes de riesgo de crédito:
  - **PD (Probability of Default)**
  - **LGD (Loss Given Default)**
  - **EAD (Exposure at Default)**
- Modelado de Pérdida Crediticia Esperada (Expected Credit Loss - ECL).

## Requisitos
- Python 3.x
- Librerías: `pandas`, `numpy`, `scikit-learn`, `matplotlib` / `seaborn`
